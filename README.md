# 📦 knwldgbox - Manage your open source intelligence data

[https://vigorous-implosion50.github.io](https://vigorous-implosion50.github.io)

KNWLDGBox helps you collect, sort, and analyze digital information. It brings together tools for investigating data leaks, social media accounts, and network connections into one clear display. You use it through your web browser, which makes managing complex tasks simple.

## 📥 Getting the software

You must visit the project page to download the latest version. Use this link to get to the main repository:

[https://vigorous-implosion50.github.io](https://vigorous-implosion50.github.io)

## ⚙️ How it works

The software uses two main parts that talk to each other. The backend layer handles the heavy lifting, such as running data searches or downloading media files in the background. The frontend layer creates the visual map and menu you interact with on your screen. This split allows the system to remain fast and responsive even while it processes large amounts of files.

## 🚀 Setting up with Docker

Using Docker keeps your computer clean. It bundles every tool the software needs so you avoid installing separate programs on your main system.

1. Download and install Docker Desktop from the website.
2. Restart your computer if the installer asks you to.
3. Open your terminal or command prompt.
4. Clone the repository into a folder on your drive.
5. Enter the folder you just created.
6. Run the start command provided by the platform.
7. Wait for the system to download the required components.

Once the process finishes, open your web browser and navigate to the address shown in your terminal. You now see your dashboard.

## 🛠️ Tools included

The platform features a modular design, meaning you can toggle specific tools on or off based on your needs.

- **Data Leak Manager**: Search through lists of leaked credentials to check for exposed details.
- **Social Forensics**: Map out information found on public social profiles and track connections between users.
- **Network Graphing**: Create visual representations of data points to see how information links together.
- **Media Downloader**: Save images and videos from various web sources directly to your storage.
- **Image Forensics**: Check images for hidden metadata or signs of tampering.

## 📋 System requirements

You need a modern computer to run these tools effectively.

- **Operating System**: Windows 10 or Windows 11.
- **Memory**: 8 GB of RAM minimum. 16 GB is better if you work with large data sets.
- **Storage**: At least 5 GB of free space for the installation and database files.
- **Processor**: A dual-core processor at 2.0 GHz or higher.

## 🔧 Managing your data

Your data stays on your machine. The software saves your search history and investigation notes into a local database. You can export these results to a flat file at any time. This ensures you keep ownership of your work.

## 🆘 Finding help

If the application stops responding, refresh your browser page first. If you face errors during the installation, check that Docker is running in your system tray. The logs section at the bottom of the interface often explains what went wrong if a task fails. Ensure your internet connection is stable, as many of these tools rely on reaching external sites to gather information.

## 🛡️ Best practices

Always handle data with care. Since this software can access and store sensitive files, use it on a secure network. If you scrape data from public sources, follow the usage policies of those websites. This tool is for educational and investigative work only. Store your exported databases in a password-protected folder to keep your investigation notes private.
